# Estratégia SEO Completa - BPR Shop

## Objetivo
Posicionar o shop da BPR no Google para palavras-chave de alta intenção relacionadas a produtos 3D de cuidado com os pés, reabilitação e suporte plantar.

## Palavras-chave Principais

### Tier 1: Alta Intenção Comercial (foco principal)
Estas são as palavras que convertem melhor:

- `3d printed insoles uk`
- `custom foot support 3d printed`
- `toe spacers for bunions`
- `arch support inserts`
- `heel lift for plantar fasciitis`
- `plantar fasciitis support products`
- `bunion relief products`
- `custom insoles near me`
- `3d printed orthotics`
- `foot recovery kit`

### Tier 2: Intenção Média (conteúdo e SEO orgânico)
Boas para blog posts e páginas educacionais:

- `how to relieve plantar fasciitis`
- `best arch support for flat feet`
- `toe spacers benefits`
- `custom vs generic insoles`
- `3d printing for foot care`
- `orthotic accessories`
- `foot pain relief products`
- `metatarsal support pads`

### Tier 3: Informacional (topo do funil)
Para atrair audiência e educar:

- `what causes plantar fasciitis`
- `bunion treatment options`
- `arch support vs insoles`
- `foot biomechanics basics`
- `recovery from foot pain`

## Landing Pages para Google Ads

### Estrutura ideal
1. **Hero:** problema + solução
2. **Benefícios:** 3-4 bullet points
3. **Produto:** imagem + especificações
4. **Prova social:** reviews ou casos
5. **CTA:** botão claro
6. **FAQ:** 3-5 perguntas
7. **Garantia/Política:** confiança

### Exemplo de copy para landing page
```
Headline: 3D Printed Toe Spacers for Bunion Relief
Subheadline: Clinically designed, printed in-house, available in 3 sizes

Benefits:
✓ Reduces bunion discomfort
✓ Medical-grade TPU material
✓ Designed by physiotherapists
✓ Made to order in the UK

CTA: Shop Toe Spacers →
```
