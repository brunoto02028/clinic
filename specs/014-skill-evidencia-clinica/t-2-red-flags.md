# T-2: references/red-flags.md — checklist de segurança

**Status:** pendente
**Depende de:** nenhuma

## Objetivo
Escrever o checklist de **red flags** de fisioterapia/reabilitação que é verificado ANTES
de qualquer busca de evidência. É a parte mais importante da skill.

## Contexto
- Se qualquer sinal estiver presente → a skill para e emite só o alerta. Sem sugestão.
- Deve ser legível por humano e acionável pela skill (lista clara, por região/sistema).

## Passos
1. Listar red flags reconhecidas, agrupadas: neurológicas (síndrome da cauda equina,
   déficit neurológico progressivo), fratura/trauma, malignidade (história de câncer, perda
   de peso inexplicada, dor noturna), infecção (febre, uso de drogas IV), vascular (sinais
   de TVP/TEP), inflamatória sistêmica, e "bandeiras" específicas por região quando útil.
2. Para cada uma: como reconhecê-la a partir dos dados de triagem, e a ação (parar +
   encaminhar para avaliação humana prioritária).
3. Deixar explícito que a lista é conservadora: na dúvida, tratar como red flag.
