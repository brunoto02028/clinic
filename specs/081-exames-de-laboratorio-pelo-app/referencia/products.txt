 Products
 Retrieve test products with pricing, biomarkers, images, shipping options, and more.
 List all products
 GET 
 /api/product/ 
 Returns a paginated list of products available for your brand. By default, only products marked for external display are returned.

 The list endpoint returns a compact representation of each product. To get full details including description, images, and slug, use the single product endpoint below.
 Get a single product
 GET 
 /api/product/{id} 
 GET 
 /api/product/slug/{slug} 
 Retrieve a single product by its UUID or slug. This returns the full product representation including description, images, discounted pricing, turnaround time, and sample collection instructions.

 Sample collection method
 Every product carries an appointment_only boolean, returned by both the list and single product endpoints. Use it to tell whether a product can be sold as a self-collected postal kit or whether the sample has to be taken by a professional.
 Value 
 Meaning 
 false 
 The product can be fulfilled as a posted home kit. It can also be booked as an appointment if a suitable shipping method is chosen. 
 true 
 The sample must be collected at an appointment by a professional (e.g. a venous blood draw). The product cannot be posted out as a kit. 
 Adding an appointment_only product to POST /api/order/ is rejected with
 "Product '…' not available for postage. Available for appointment only." Check this flag before
 offering a product for postal fulfilment, and book an appointment for it instead — see
 Booking appointments .
 To find out which delivery or appointment options a specific product supports, call the /api/product/{id}/shipping sub-resource documented below — it lists the shipping methods (postal, onsite, courier, at-home phlebotomist) available for that product.
 Product sub-resources
 Each product has several related resources available as separate endpoints. All sub-resource endpoints return paginated responses.

 Images
 GET 
 /api/product/{id}/files 
 Returns the images associated with this product. Each file includes the original URL and generated thumbnail URLs in multiple sizes.

 Categories
 GET 
 /api/product/{id}/categories 
 Returns the categories this product belongs to.
 FAQs
 GET 
 /api/product/{id}/faqs 
 Returns the frequently asked questions for this product.
 Video
 GET 
 /api/product/{id}/video 
 Returns the video associated with this product, or null if none exists. This endpoint returns a single object, not a paginated response.
